# Checklist final obrigatório

Antes de finalizar qualquer tarefa, validar:

## Design System
- [ ] DS consultado
- [ ] tokens utilizados
- [ ] componentes oficiais reutilizados
- [ ] sem cores hardcoded
- [ ] sem spacing arbitrário
- [ ] sem font-size arbitrário
- [ ] sem botão cru
- [ ] sem input cru
- [ ] sem select cru
- [ ] sem logo duplicado

## Negócio
- [ ] regras existentes respeitadas
- [ ] permissões preservadas
- [ ] estados válidos
- [ ] fluxos clínicos preservados
- [ ] mensagens adequadas

## Arquitetura
- [ ] sem duplicação desnecessária
- [ ] sem lógica de negócio em componente visual
- [ ] sem acoplamento indevido
- [ ] componentes reutilizáveis
- [ ] organização preservada

## UX
- [ ] loading tratado
- [ ] erro tratado
- [ ] estado vazio tratado
- [ ] feedback claro
- [ ] ações compreensíveis
- [ ] densidade institucional preservada

## QA
- [ ] lint executado, se disponível
- [ ] build executado, se disponível
- [ ] testes executados, se disponíveis
- [ ] rotas principais verificadas
- [ ] regressões documentadas
