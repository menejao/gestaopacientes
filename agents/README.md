# Agents VALENS

Esta pasta define os agents/guardians permanentes do projeto VALENS.

Eles funcionam como contrato de qualidade para qualquer alteração no sistema.

Agents disponíveis:

- Design System Guardian
- Business Rules Guardian
- Architecture Guardian
- UX Flow Guardian
- QA Regression Guardian

Anexos de apoio:

- `permissions-matrix.md`
- `design-system-matrix.md`

Todo desenvolvimento deve seguir:

1. regras do agent correspondente;
2. workflow obrigatório;
3. checklist final;
4. relatório final em pt-BR.

Nenhuma alteração deve violar o Design System, as regras de negócio ou a arquitetura do projeto.
