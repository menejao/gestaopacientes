# Rotina Mensal de Auditoria

## 1) Revisao de acesso
- Listar todos os usuarios por equipe.
- Remover/desativar quem nao atua mais.
- Confirmar 2FA ativo para perfis clinicos.

## 2) Revisao de logs
- Amostragem das acoes criticas:
  - exclusao de pacientes;
  - exclusao de registros;
  - alteracao de protocolos;
  - alteracao de contas.

## 3) Revisao de dados
- Conferir qualidade de dados:
  - sem telefone;
  - sem ACS;
  - CPF/CNS duplicado.
- Definir plano de saneamento para itens pendentes.

## 4) Backup e restauracao
- Verificar se houve backup semanal em todo o mes.
- Testar restauracao em ambiente de teste.

## 5) Ata mensal
Registrar:
- data da revisao;
- participantes;
- riscos identificados;
- acoes corretivas com prazo e responsavel.
